# Khiops Labs

This section collects code repositories and projects that demonstrate how Khiops can be applied to specific technical or methodological topics.

It is **community-oriented and open to contributions**. Whether you’re experimenting with a new application domain or building operational pipelines with Khiops, feel free to fork, reuse, or submit your own recipe.

!!! example "Released as is, with no official support"
    Projects referenced here are experimental by nature and not part of the official Khiops distribution. They are maintained independently by contributors and may evolve rapidly. We do not provide official support.

## Khiops Enneade 

Khiops Enneade is a tool which produces a clustering model using a modified version of the K-Means algorithm. Khiops Enneade is available both in user interface mode and in batch mode, such that it can easily be embedded as a software component in a data mining deployment project.

Source is available on this [:material-github: repository](https://github.com/KhiopsML/enneade) (:octicons-tag-24: v10.1.0)

# 🛠️ Reporting an Issue

Found a bug, documentation typo, or installation issue? Here’s how to report it effectively.

## ✅ Choose the Right Repository

Khiops is organized into multiple open-source components. To ensure your issue is addressed efficiently, please open it in the appropriate GitHub repository:

| Use case                                                                 | Repository                                                                 |
|--------------------------------------------------------------------------|----------------------------------------------------------------------------|
| Core engine issues (modeling, algorithms, CLI crashes)                  | [khiops-core](https://github.com/KhiopsML/khiops-core)                     |
| Python package (pip/conda install, `khiops` or `khiops_coclustering` API) | [khiops-python](https://github.com/KhiopsML/khiops-python)                 |
| Docker/Kubernetes packaging and CI/CD                                    | [khiops-docker](https://github.com/KhiopsML/khiops-docker)                 |
| Cloud storage access (GCS, S3, Azure, HDFS...)                           | [khiops-drivers](https://github.com/KhiopsML/khiops-drivers)               |
| Website content, tutorials, guides                                       | [khiops-doc](https://github.com/KhiopsML/khiops-doc)                       |
| General questions or unclear issue ownership                             | [Discussions](https://github.com/orgs/KhiopsML/discussions)                |

## 🧭 How to Create a Good Issue

- ✅ Be descriptive: what happened, what did you expect?
- 💻 Share your environment: OS, version (khiops --version), Python version, etc.
- 📎 Include logs or screenshots where possible
- 🔁 Can you reproduce the issue? If yes, please share steps or a small data sample

If you’re not sure where to post or it feels more like a question than a bug — start in the Discussions. We’ll help you triage it.
